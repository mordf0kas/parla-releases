# PARLA — downloads

Talking-reese effect plugin (VST3/Standalone) by DRELVA. Put a synth through it and it rolls
and talks like a reese bass: clean mono sub below 150 Hz, detuned 4-voice beating, drive,
host-synced vowel sequencer with robot syllables, and a comb tuned to PITCH.

This repo hosts only the downloads — no source code (that lives in a private repo).

See the [Releases](../../releases) tab for the Windows build. The build is unsigned: click
"More info" → "Run anyway" on the SmartScreen warning for the standalone.
